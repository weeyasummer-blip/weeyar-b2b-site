WEEYAR V95 首页更新包｜部署说明

本包保留 Products、OEM / ODM、About Us、Contact、产品详情页、SEO 文件和 Vercel 配置，只更新 HOME 首页。

部署步骤：
1. 登录 https://github.com，打开当前连接 weeyar.com 的 weeyar-b2b-site 仓库。
2. 先点 Code → Download ZIP，保存当前版本作为备份。
3. 解压本更新包。
4. 在 GitHub 仓库点 Add file → Upload files。
5. 把解压后文件夹“里面”的所有文件和文件夹拖进去。不要把最外层文件夹再套进去。
6. 页面底部填写 Update V95 homepage，然后点 Commit changes。
7. Vercel 会自动部署。通常等待 1–3 分钟后访问 https://weeyar.com。
8. 如果没变化，Windows 浏览器按 Ctrl + F5 强制刷新。

回退：GitHub 打开 Commits，找到 Update V95 homepage，选择 Revert；或重新上传第 2 步保存的旧版本。
